# Contributing

Use a focused branch and pull request. Add or update tests for behavioural changes. Do not weaken environment allowlisting, revision guards, size limits or idempotency protections without an explicit security rationale.

AI-assisted contributions are welcome when the contributor reviews and takes responsibility for the submitted code, tests it, discloses material AI assistance in the pull request, and confirms they have the right to submit the resulting work. Do not paste confidential material into AI systems or submit generated code whose licence/provenance is uncertain.
